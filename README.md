# 🧙‍♀️🍎 Hechizos de la Yaya

Juego de unir 3 para la yaya Ana: manzanas, brujas, escobas, calabazas, lunas y calderos en un bosque encantado.

- 🗺️ 50 niveles: juntar fichas, quitar telarañas, abrir candados y conseguir puntos.
- ⚡ Rayo (4 en fila), 💣 bomba (L o T) y 🔮 bola de cristal (5 en fila). Dos especiales juntos hacen un hechizo enorme.
- 🧪 Pociones: dan 5 movimientos más. Se recargan solas (una cada 20 minutos) y se ganan cumpliendo la misión de cada nivel.
- 🔠 Tres tamaños de letra, sin reloj ni prisas, con pista si no ves ninguna jugada.
